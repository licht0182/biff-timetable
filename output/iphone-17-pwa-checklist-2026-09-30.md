# iPhone 17 설치형 PWA 확인표

대상: [BIFF Timetable](https://licht0182.github.io/biff-timetable/) · 확인 기기: iPhone 17

자동화 결과와 별개로 실제 설치 앱에서 확인할 항목이다. iOS 버전: ______ / 확인 날짜: ______

## 준비

1. 현재 시간표가 있다면 설정의 백업 기능으로 파일을 저장한다.
2. 인터넷이 연결된 상태에서 Safari로 사이트를 연다. 홈 화면에 아직 없다면 공유 메뉴의 홈 화면 추가로 설치한다.
3. 홈 화면 아이콘으로 앱을 열고 영화 목록과 AI 도슨트 칼럼을 확인한다. 대표 작품은 사진 대신 작품명과 도형이 보여야 한다. 이미 설치했던 앱에 사진이 남아 있으면 온라인 상태로 앱을 닫았다 다시 열어 새 버전을 받은 뒤 확인한다.

## 약 10분 확인

| 항목 | 확인 방법 | 정상 기준 | 결과 |
|---|---|---|---|
| 오프라인 재진입 | 온라인에서 영화 목록·도슨트를 한 번 연 뒤 앱을 닫는다. 비행기 모드를 켜고 Wi-Fi도 끈 다음 홈 화면 아이콘으로 다시 연다. | 영화 목록·저장 시간표·도슨트 글과 자체 그래픽이 표시된다. 추천 넘기기와 칼럼 읽기가 가능하다. | ☐ 통과 ☐ 문제 |
| 키보드 | 온라인으로 돌아와 영화 찾기의 검색창을 누르고 한글 작품명을 입력한다. 결과를 선택한 뒤 키보드를 닫는다. | 입력창과 검색 결과가 보이고 키보드가 닫힌 뒤 화면 높이·하단 탭이 회복된다. | ☐ 통과 ☐ 문제 |
| 긴 글·갤러리 | 도슨트에서 추천을 좌우로 넘기고, 칼럼을 끝까지 스크롤한다. 맨 위로·목록으로를 누른다. | 세로 스크롤과 가로 넘기기가 서로 방해하지 않는다. 버튼이 눌리고 화면 밖으로 글이 넘치지 않는다. | ☐ 통과 ☐ 문제 |
| 시간표·확인창 | 영화 회차를 시간표에 추가하고 상세창·닫기를 사용한다. 대안이 있는 예매 계획에서 적용 확인창을 연다. | 버튼·확인 문구가 보이고 닫기 후 원래 위치로 돌아온다. 저장한 일정이 앱 재실행 후 유지된다. | ☐ 통과 ☐ 문제 |
| 화면 하단 | 네 탭을 바꾸며 가장 아래까지 스크롤한다. | 홈 표시줄과 하단 탭이 겹치지 않고 마지막 항목·버튼을 누를 수 있다. | ☐ 통과 ☐ 문제 |
| 다크 모드 | 시스템 화면 모드를 어둡게 바꿔 목록·시간표·확인창·도슨트를 연다. | 주요 글자와 버튼이 읽히고 배경 글자가 확인 문구를 가리지 않는다. | ☐ 통과 ☐ 문제 |
| VoiceOver | 설정 → 손쉬운 사용 → VoiceOver를 켠다. 탭·검색창·영화 카드·상세창 닫기·추천 이전/다음을 차례로 탐색한다. | 항목 이름과 선택 상태가 읽힌다. 상세창이 열린 동안 초점이 창 밖으로 나가지 않고 닫은 뒤 호출한 항목으로 돌아간다. 작품명은 장식 그래픽 때문에 중복 낭독되지 않는다. | ☐ 통과 ☐ 문제 |

확인 후 비행기 모드·VoiceOver·화면 모드는 원래 설정으로 돌린다.

## 회신 양식

`iOS __ / 오프라인 __ / 키보드 __ / 갤러리 __ / 확인창 __ / 하단 __ / 다크 __ / VoiceOver __`

문제가 있으면 **어느 탭에서 무엇을 누른 뒤 발생했는지**, 예상과 실제 동작, 가능하면 화면 캡처를 함께 남긴다. 아직 확인하지 않은 항목은 `미확인`으로 적는다.
