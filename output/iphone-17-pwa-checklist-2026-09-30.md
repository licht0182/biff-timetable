# iPhone 17 최초 확인 결과와 이후 검증 기준

대상: [BIFF Timetable](https://licht0182.github.io/biff-timetable/) · 기기: iPhone 17 · 사용자 회신: 2026년 9월 30일

사용자는 준비한 실기기 확인표의 **모든 항목이 통과**했다고 회신했다. 아래는 사용자 확인 결과를 기록한 것이며, 자동화의 실기기 측정 결과가 아니다. iOS 버전은 별도로 제공되지 않았다.

| 최초 확인 항목 | 결과 |
|---|---|
| 설치형 앱의 오프라인 재진입 | 통과 |
| 소프트 키보드 입력과 화면 회복 | 통과 |
| 긴 글 스크롤과 갤러리 탐색 | 통과 |
| 시간표·확인창·저장 유지 | 통과 |
| 하단 탭과 홈 표시줄의 안전 영역 | 통과 |
| 다크 모드 가독성 | 통과 |
| VoiceOver 탐색과 초점 복귀 | 통과 |

## 이후 검증 정책

사용자 지시: **“pwa는 앞으로 체크하지 말고 일반 사이트에서 통과가 되면 pwa도 통과한 것으로 간주해.”**

- 별도 PWA 자동화·실기기 검사를 반복하지 않는다.
- 일반 사이트의 Chromium·iPhone WebKit 기능·레이아웃·접근성과 공개 배포 결과를 검증한다.
- 일반 사이트가 통과하면 PWA도 통과로 판정한다.
- 기존 PWA 기능은 유지한다.
