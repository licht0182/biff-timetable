# 내 시간표 목록 겹침 수정

## 재현과 원인

사용자가 지목한 `내 시간표 → 목록`을 확인했다. 긴 사용자 일정 제목과 장소가 있는 카드에서 텍스트가 삭제 버튼을 침범했다.

- 320px 화면: 제목 침범 약159px, 장소 침범 약71px, 카드 내부 가로 넘침106px.
- 390px 화면: 제목 침범 약89px, 카드 내부 가로 넘침36px.
- 원인: `.schedule-list-copy`의 내부 grid 열이 기본 `auto`라서 `word-break:keep-all`인 긴 단어의 최소 콘텐츠 폭으로 늘어났다. 부모의 `min-width:0`만으로 내부 열이 줄어들지 않았다.

## 수정

- 내부 텍스트 열을 `minmax(0,1fr)`로 지정한다.
- 제목·장소 요소의 최소 폭을0으로 하고 `overflow-wrap:anywhere`로 필요한 경우 줄바꿈한다.
- 전체 제목과 장소를 표시하며 카드 높이가 내용에 맞춰 늘어난다. 카드 형태, 왼쪽 정렬, 알약형 버튼과 색상만 바뀌는 누름 반응을 유지한다.

## 검증

- 실제 빌드를 Chromium/WebKit에서 직접 촬영했다.
- 폭320·390·700·768·1440px 모두 제목·장소·버튼 침범0px, 카드·페이지 가로 넘침0px.
- 실제 상영 `백 투 부에노스아이레스`와 `텐더 러빙 케어`를 예매 대안으로 넣고, 실패 상태의 ‘시간표에 적용’ 버튼도 함께 확인했다.
- 긴 사용자 일정과 장소, 밝은/어두운 화면을 확인했다.
- TypeScript/Vite 빌드 통과. 목록·가독성·버튼 회귀 검사26개 통과, 실패·제외·재시도 없음.
- 긴 텍스트 조각이 버튼과 카드 밖으로 나가지 않는 검사를320·390·768px에 추가했다.
- 별도 PWA 점검 없이 일반 사이트 검증을 적용한다.
- 새 독립 검토 SHIP. 수정 전후 화면과 실제 텍스트 조각 경계 검사, 동일 소스 지문을 독립적으로 확인했다. 커밋·배포 결과는 별도 배포 확인 보고서에 기록한다.
